The goal of this project is to explore how an image changes when we separate its smooth structure from its fine details. I start with convolution and edge detection, then use those ideas to sharpen images, create hybrids, and blend different scenes.

Part 1 / Fun with filters

1.1 /

Convolutions from scratch

Four-loop implementation · NumPy only 
def convolution_four_loops(img, kernel):
    flipped = np.flip(kernel)
    fh, fw = flipped.shape
    padded = np.pad(img, ((fh // 2, fh // 2), (fw // 2, fw // 2)))
    result = np.zeros(img.shape, dtype=np.float64)
    for r in range(img.shape[0]):
        for c in range(img.shape[1]):
            for kr in range(fh):
                for kc in range(fw):
                    result[r, c] += padded[r + kr, c + kc] * flipped[kr, kc]
    return result
Two-loop implementation · NumPy only 
def convolution(img, kernel, padding_mode='constant', use_lib=False):
    flipped = np.flip(kernel)
    fh, fw = flipped.shape
    padded = np.pad(
        img, ((fh // 2, fh // 2), (fw // 2, fw // 2)), mode=padding_mode
    )
    result = np.empty(img.shape, dtype=np.float64)

    for r in range(img.shape[0]):
        for c in range(img.shape[1]):
            window = padded[r:r + fh, c:c + fw]
            result[r, c] = np.sum(window * flipped)
    return result

Here is an example of applying the convolution to my selfie, with the kernel as the box, diff of x and diff of y filters. The box filter averages 81 pixels, softening small details. The difference filters respond to changes across columns and rows: Dx emphasizes vertical boundaries, while Dy emphasizes horizontal ones.

1.2 /

Finite Difference Operator

This part is trying to use the difference operators to find edges in an image. An edge is an area in the image where intensity changes quickly. To find this, I convolve the image with Dx and Dy to get the horizontal and vertical edges, then combine the two into a gradient magnitude. Finally, thresholding that magnitude gives a binary edge map. White for edges, black for non-edges.

Ix = I * Dx   ·   Iy = I * Dy   ·   M = √(Ix² + Iy²)   ·   edges = M > 0.35

I use a threshold of 0.35 on intensities [0, 1] because I think the edges that matter here are the subject (cameraman, camera, tripod) and everything else is just stuff and noise (grass texture, background building). The tradeoff is that weaker background edges and some parts of the tripod disappear. Lowering the threshold would recover more of them, along with more noise.

1.3 /

Derivative of Gaussian (DoG) Filter

The problem with the previous approach is that finite differences responds to small intensity fluctuations. Thus, the motivating idea here is what if we smooth the image first then differentiate.

Convolution is associative, so I can instead convolve the Gaussian with each difference filter and apply the resulting derivative-of-Gaussian (DoG) kernel directly to the image. I use mode='full' when constructing these kernels so their support is not cut off. Note: middle gray denotes zero in the signed kernel visualizations.

(I * G) * Dx = I * (G * Dx)   ·   similarly for Dy

Two steps: Gaussian, then finite differences

One step: derivative-of-Gaussian filters

Compared with the raw finite differences, the smoothed edges are broader and more continuous, with less fine texture in the grass. I lower the threshold to 0.10 because smoothing also reduces gradient strength. This keeps the main silhouette and more of the horizon without bringing back all the original texture.

Why build a DoG filter? Simply because it shows that convolution is associative. One can precompute G * Dx and G * Dy and apply each filter in one pass. The derivatives match the blur-then-difference result in the image. But do note that a single dense DoG convolution may not be computationally cheaper.

Part 2 / Fun with frequencies

2.1 /

Image "Sharpening"

A Gaussian blur (also called a low pass filter) keeps smooth, low-frequency structure. Subtracting it from the original image isolates high frequencies, such as edges and fine texture. Unsharp masking adds a scaled version of that residual back to the original, making existing high frequencies more pronounced.

Blur = Im * Gaus   ·   H = Im − Blur   ·   Result = Im + αH = Im * [(1 + α)δ − αGaus]

The last expression combines sharpening into one convolution: δ is an impulse kernel with a 1 at the center and 0 everywhere else. I apply the filter separately to R, G, and B, using the same 9 × 9 Gaussian as above, then clip the displayed result to [0, 1]. High-frequency panels are shown as H + 0.5, so zero detail appears gray.

Taj Mahal

Another example: the building

The effect is most visible in the Taj Mahal’s carvings and the building’s stairs, paving, and bicycle. Sharpening raises local contrast around these structures, but it does not create new information.

What If We Keep Increasing Alpha

At α = 1, the edges become clearer without overwhelming the image. Larger values however, makes the images look increasingly harsher with stark bright and dark contrast.

Can Sharpening Undo Blur?

The cup rim and ice look crisper after sharpening, but they do not recover all the original texture. Remember, blurring smoothens high frequencies, and sharpening can only amplify what remains, it cannot reconstruct detail that was lost.

2.2 /

Hybrid Images

Now we come to my favorite part of this project: hybrid images! It essentially combines the low frequencies of one image with the high frequencies of another. This phenomena arises from the biology of our eyes, where up close we can focus on high frequency details better, and from a far lower frequencies dominate. Aligning corresponding features helps the two interpretations occupy the same place.

Low = Im₁ * Gausσ₁   ·   High = Im₂ * (δ − Gausσ₂)   ·   hybrid = clip(0.8L + 1.25H, 0, 1)

I use the supplied two-point alignment code to match centers, scale, and rotation, then crop to a common shape. The filters have configurable height and width set at 2⌊3σ⌋ + 1 (to make it odd). I also adjusted the final intensities of the low freq (0.8) and high freq (1.25) images to make the effect better. Further, I erode the nonzero support of the high-frequency source before combining it, which suppresses artificial edges introduced by its black alignment padding.

Alignment and filtering

For this result, σ₁ = 0.5 gives a 3 × 3 low-pass kernel, while σ₂ = 3 gives a 19 × 19 high-pass kernel. A larger Gaussian σ removes a wider range of detail from the low-pass image; in the high-pass branch, it includes more medium-scale detail in the residual. Here the small σ₁ preserves the younger face clearly, but also leaves more overlap between the two sources’ frequency bands.

Looking at the Fourier spectra

The low-pass spectrum remains concentrated near the center; the high-pass spectrum suppresses the center and retains more distributed detail. The hybrid contains both. 2.3 /

Gaussian and Laplacian stacks

A stack separates an image into scales without changing its dimensions. I start with G₀ = Im and successively blur the previous level with σ = 1, 2, 4, 8, and 16. Each blur is applied horizontally and vertically with a 1D Gaussian and mirrored boundaries (this is faster than applying a 2D Gaussian). There is no downsampling (unlike a laplacian pyramid).

Lapli = Gausi − Gausi+1   (i = 0, …, 4)   ·   Lapl₅ = Gaus₅   ·   Im = Σ Lapli

Each Laplacian level contains what disappears between two successive Gaussian levels. The final level stores the remaining low-frequency image. Adding all six levels reconstructs the original.

2.4 /

Multiresolution Blending (a.k.a. the oraple!)

The motivating reason behind blending is that a direct cut between 2 images makes the color change obvious. Multiresolution blending makes that cut seamless. It blends the two images separately at each frequency band: narrow for fine texture, wider for large changes in color and illumination. To achieve this, I build Laplacian stacks for both images and a Gaussian stack for the mask.

Bluri = Maski LaplA,i + (1 − Maski) LaplBlur,i   ·   result = clip(Σ Bluri, 0, 1)

White in the mask selects source A, black selects source B, and intermediate values mix them. The same mask is applied to each RGB channel. Because these are stacks, reconstruction is a sum over levels; no upsampling is needed.

The oraple

Blending keeps the apple and orange textures while spreading the color transition over a wider area. The two fruit silhouettes already line up well, which helps the seam disappear.

03 /

Reflection

The most important thing I learned is that an image’s identity and its fine detail can live at different scales. The same Gaussian filter that removes noise before edge detection also separates the pieces needed for sharpening, hybrid images, and blending.

I also learned that better filtering does not fix every mismatch. Sharpening cannot fully undo blur, hybrid images need compatible geometry, and a smooth blending mask cannot correct different lighting. The results work best when the filtering method and the input images support the same goal.
