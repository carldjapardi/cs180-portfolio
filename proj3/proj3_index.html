Fun with Flow Matching!

From restoring noisy photos to making visual illusions, this project explores what a learned velocity field can do. First I use a pretrained image model, then train small UNets on handwritten digits.

Full report PDF

Part A / Exploring pretrained flow models

I use PixNerd-XXL-P16-T2I to predict a velocity field for 512 × 512 RGB images. All integration states and model evaluations use float32. Time runs from noise at 0 to a clean image at 1. The building and matcha photos are mine, reused from Project 2. The flower and house are my hand-drawn sketches.

xt = (1 − t)ε + tx1; target velocity = x1 − ε

1.1 Constructing noisy inputs

I center-crop the building photo to a square, resize to 512 × 512, and map RGB to [−1, 1]. The same Gaussian noise tensor, seed 180, is reused at all three times. Increasing t retains more of the photo. The endpoint checks return exactly the noise at t = 0 and the original at t = 1.

1.2 Gaussian denoising

I divide each noisy input by t before blurring to restore the image amplitude. I compare σ ∈ {1, 2, 4, 8, 16} and choose the lowest reconstruction MSE against the known original. This is an image-specific baseline: t = 0.25: σ = 8, t = 0.5: σ = 4, t = 0.75: σ = 1.

At t = 0.25, the large blur needed to suppress noise also removes the railing, bike, and paving detail. At t = 0.50 the building layout is clearer, but colored noise remains. At t = 0.75, much less blur is needed because the original contributes more strongly to the input.

1.3 One-step denoising

With the prompt “a high quality photo”, one velocity prediction estimates the endpoint as x̂1 = xt + (1 − t)v̂. The multiplier is the remaining time. Even at t = 0.25, the model recovers the broad building layout and the bike position, but edges and textures are soft. More of the original detail survives at later times. A single prediction cannot fully account for how the learned velocity changes along the remaining path.

1.4 What the model adds

The predicted update is (1 − t)v̂; the exact update is x1 − xt. For each pixel, I square the RGB update differences, average across the three channels, then take the square root. These errors are computed before clipping. All signed updates use the same symmetric range ±4.336, with zero at middle gray. All heatmaps share the linear range [0.000, 1.612].

The predicted and exact updates have similar noise-cancelling structure, but the error map highlights fine edges such as the railing, bike, and paving joints. These are details that the one-step estimate smooths or changes. The shared display limits make the three times comparable.

1.5 Euler denoising

I recompute velocity after every update x ← x + hv(x, t), using h = 0.02. From t = 0.50, this takes 25 updates. The trajectory includes the initial state, every fifth update, and the endpoint. Constant-velocity checks pass for 50 steps, 25 steps, and a shortened final step starting at 0.93.

Method at t = 0.50Reconstruction MSE in [−1, 1]
Gaussian blur0.035854
One step0.009686
Euler0.011088

Euler produces sharper paving, brickwork, and bike details than the one-step estimate. However, it also changes small structures instead of exactly restoring them. Here one-step denoising has the lowest pixel MSE, while Euler looks sharper. This illustrates that plausible learned detail and pixel-accurate reconstruction are different goals.

1.6 Generating from pure noise

Each image starts from independent Gaussian noise and uses 50 Euler updates with the prompt “a high quality photo”. The seeds are 180–184.

All five results tend toward portraits despite the generic prompt. Some have malformed facial details, especially the first and fourth samples. This small set suggests a strong portrait tendency for this prompt and seed range; it is not a complete characterization of the training data.

2.1 Classifier-free guidance

vcfg = vc + w(vc − vu), w = 7

The unconditional branch uses the empty prompt. Both predictions receive the same state and time. I verify that w = 0 equals the conditional prediction exactly. These images reuse the five initial noise tensors from Section 1.6.

Guidance makes faces cleaner and more sharply defined for these same five seeds, reducing several obvious facial artifacts. It also changes identities, clothing, and composition, rather than simply sharpening the earlier image. The results remain concentrated on portraits and have a more uniform portrait style.

3.3 Visual anagrams

At each Euler step, I average the guided velocity in the normal orientation with the guided velocity of the 180°-rotated image, rotated back. Rotation flips both spatial axes. Applying it twice restores the original tensor exactly. Both experiments use h = 0.02 and w = 7.

Jellyfish / bouquet of flowers

Seed: 180.

Mushroom / hot-air balloon

Seed: 181.

The jellyfish bell reads as a blue vase after rotation, while the tentacles become flower stems. Blue and pink petals are visible in both orientations, so the two readings share recognizable details. The mushroom/balloon pair is less clean: upright, an orange cap and pale stem-like shapes suggest a mushroom; rotated, the rounded lower region becomes the balloon envelope and the small shape below becomes a basket. The doubled stem and visible basket structure weaken the mushroom reading. I compared five mushroom/balloon candidates and retained the original seed-181 result; extra seeds and more detailed prompts did not improve both readings together.

3.4 Hybrid images

v = lowpass(va) + vb − lowpass(vb)

The low-frequency prompt supplies the distant structure; the high-frequency prompt supplies the close detail. I use a 265 × 265 Gaussian kernel with σ = 16 at every step, h = 0.02, and w = 7. The small previews below simulate viewing from farther away.

Mountains / ocean waves

Far: “a lithograph of three tall mountain peaks silhouetted against a white sky”. Close: “a lithograph of ocean waves”. Seed: 42.

Whale / galaxy

Far: “an oil painting of a dark whale silhouette in side view on a pale background”. Close: “an oil painting of a galaxy”. Seed: 43.

The mountain/wave hybrid uses a broad triangular dark ridge as mountain-like structure at a distance and curling crests as ocean detail up close. The waves remain recognizable in the small preview, so the mountain interpretation is weak rather than a clean perceptual switch. In the whale/galaxy hybrid, the large dark mass and tail-like extension suggest a whale from farther away, while close inspection reveals stars and diffuse galaxy texture. Its contour and flippers are indistinct, so the animal reading remains ambiguous. For each pair I compared five candidates, including the original short prompt and two more explicit compositions with two seeds each. The selected seeds are 42 and 43. These were more readable than the initial trials, but neither fully separates its two subjects.

Part B / Training flow matching from scratch

I train on all 60,000 MNIST training images, scaled to [0, 1]. The 10,000 test images are reserved for visual evaluation and are never used for optimizer updates. Each batch gets fresh independent Gaussian noise. All runs use seed 180, Adam, and float32 tensors. The denoiser ran on a Tesla T4; the remaining runs used an A100. Losses below are mean training MSE, not test error or a measure of image quality.

1.1 UNet architecture

Each Conv block is a 3 × 3 convolution, batch normalization, and GELU. ConvBlock applies it twice. DownConv uses stride 2; UpConv is a 4 × 4 transposed convolution with stride 2. The bottleneck averages over the 7 × 7 map, then unflattens with a 7 × 7 transposed convolution. Skip connections concatenate encoder features at matching resolutions.

StageFeature shape, excluding batch
Input → ConvBlock1 × 28 × 28 → D × 28 × 28

Flatten → Unflatten2D × 1 × 1 → 2D × 7 × 7

Concat middle skip → Up 22D × 14 × 14 → D × 28 × 28
Concat first skip → output2D × 28 × 28 → 1 × 28 × 28

1.2 Adding noise

For each of three test digits, I reuse one noise tensor across σ ∈ {0, 0.2, 0.4, 0.5, 0.6, 0.8, 1.0}, forming x + σε. Only display values are clipped. The digit becomes harder to separate from the background as σ rises.

1.2.1 Learning a denoiser

I train a D = 128 UNet for five epochs with batch size 256 and learning rate 10⁻⁴. The objective is MSE between the predicted clean digit and the clean target, using σ = 0.5. The examples use the same test digits and noise at both checkpoints.

The epoch-5 model was trained only at σ = 0.5. Below, each pair of rows shows inputs and outputs for one test digit, with the same noise tensor across all seven levels. Around the training level, the displayed digits remain recognizable. At σ = 0.8 and 1.0, distortions increase; the displayed 1 gains an angled stroke. 1.2.3 Independent pure-noise baseline

I train a fresh D = 128 UNet for five epochs with the same batch size and optimizer, but replace each input with pure Gaussian noise independent of the clean digit target. No parameters are reused from the denoiser.

The outputs converge toward nearly the same blurry oval with overlapping digit strokes, rather than distinct digits. For squared error, the optimal predictor is E[x | ε]. Since ε and x are independent, this equals E[x], the average training digit. More training cannot recover a target that the input does not identify.

2.1–2.3 Time-conditioned flow matching

I use D = 64 and add two time embeddings, each Linear → GELU → Linear, at the bottleneck and first upsampled feature map. For every example I sample t uniformly in [0, 1], form (1 − t)x₀ + tx₁, and regress the velocity x₁ − x₀. Training uses batch size 64 for ten epochs, initial learning rate 0.01, and an exponential scheduler with γ = 0.1^(1/10). Sampling starts from the same 40 noise tensors at each checkpoint and uses 50 Euler steps.

At epoch 1, many outputs have broken or ambiguous strokes. At epoch 10, most are recognizable digits, although several malformed or ambiguous shapes remain. The repeated starting noise makes these changes directly comparable. Unlike independent-noise regression, the time-conditioned input follows a path toward a corresponding target, and sampling repeatedly updates the state along the learned velocity field.

2.4–2.6 Class-conditioned flow matching

I embed a ten-dimensional one-hot label with two more Linear → GELU → Linear blocks. Class embeddings scale features while time embeddings shift them. With probability 0.1, the one-hot vector is replaced by all zeros during training, so the same network learns an unconditional branch. D = 64, batch size 64, ten epochs, Adam, and the learning-rate schedule match the time-only run.

2.6 Removing the learning-rate scheduler

I replace the decaying schedule with a fixed learning rate of 0.001, compensating for the lack of late-stage decay by lowering the initial rate tenfold. Architecture, seed, training split, batch size, ten-epoch budget, class dropout, sampling steps, noise, and guidance are kept the same.

EpochMean training MSELearning rate
10.1364450.001
50.0918890.001
100.0858540.001

At epoch 10, both runs produce recognizable, class-consistent digits in the displayed 40-sample grids. The fixed-LR run has some thicker and more angular strokes. Its final mean training MSE is 0.085854, versus 0.084821 with scheduling, about 1.2% higher. Lowering the fixed rate provides a stable update size throughout training, avoiding the large late-stage updates that a constant 0.01 would retain. In this comparison the visual results are similar, but the training-loss difference and limited sample grid do not establish equal generation quality.
